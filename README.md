# houkoku-tools

介護サービス情報公表などの申請作業で、自分が実際に使うために作ったローカルWebツール集です。

## 収録ツール

- **公正中立性集計ツール**
  - カイポケのサービス利用票PDFをブラウザ内で解析し、前6か月のケアプランにおけるサービス利用割合と事業所別割合を集計します。
  - 現在は、手元で確認したカイポケPDFの帳票構造に合わせて作っています。

- **勤務表 配置監査ツール**
  - 申請用勤務表（.xlsx）をブラウザ内で読み込み、日ごとの配置不足や兼務上の確認ポイントを表示します。
  - 現在は、手元の申請用勤務表テンプレートに合わせた判定です。

## プライバシー

各ツールはブラウザ内で処理する単体HTMLとして作成しています。入力したPDFやExcelをサーバーへアップロードする処理は入れていません。

ただし、利用するブラウザ、OS、拡張機能、端末そのもののセキュリティは別途必要です。

## 注意

このリポジトリは個人の業務補助用に作ったツールを公開しているものです。
制度・法令・自治体運用の正式な判断を代替するものではありません。
申請前に、最新の公式資料と実際の勤務表・帳票を必ず確認してください。

# houkoku-tools

介護サービス情報公表などの申請作業で、自分が実際に使うために作ったローカルWebツール集です。

## 収録ツール

- **公正中立性集計ツール**
  - サービス利用票PDFをブラウザ内で解析し、前6か月のケアプランにおけるサービス利用割合と事業所別割合を集計します。
  - 現在はカイポケから出力したPDFで動作確認しています。
  - その他の介護ソフトから出力したPDFについては、帳票構造の違いにより正しく読み取れない場合があります。

- **従業者集計ツール**
  - 職種、勤務回数、勤務時間、専従・兼務などを入力し、常勤・非常勤、常勤換算人数を集計します。
  - 地域密着型通所介護の介護サービス情報公表で使用する項目をもとに作成し、地域密着型通所介護で動作確認しています。
  - 同様の従業者項目を使用する他のサービス種別でも利用できる場合がありますが、職種や記載方法が異なる場合があるため、各サービスの最新の公表項目・記載要領を確認してください。

## プライバシー

各ツールはブラウザ内で処理する単体HTMLとして作成しています。入力したPDFやExcelをサーバーへアップロードする処理は入れていません。

ただし、利用するブラウザ、OS、拡張機能、端末そのもののセキュリティは別途必要です。

## 注意

このリポジトリは個人の業務補助用に作ったツールを公開しているものです。
制度・法令・自治体運用の正式な判断を代替するものではありません。
申請前に、最新の公式資料と実際の帳票を必ず確認してください。
